## 维护规则

- `docs` 下 Markdown 文件统一使用两位编号开头和中文名称。
- 能归属到现有主题的内容直接合并，不再新增同义、临时或版本后缀文档。
- 架构、接口、数据库或部署方式变化时，同步更新对应核心文档。
- SQL 文件和原始数据文件保留技术用途的既有文件名，不受 Markdown 命名规则约束。
