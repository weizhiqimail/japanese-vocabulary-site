# 本轮改造逐项验收

1. 导航：一级、管理二级和页面导航均使用 Chakra UI `Breadcrumb`。
2. 页面目录：改为 `pages/`、`layout/`、`components/`；页面目录通过 `index.tsx` 对外暴露。
3. 页面级组件：每条路由对应独立组件；删除旧 `ResourcePage`、`DetailPage`、`StudyPage` 路由复用。
4. 表单：登录、知识编辑、集合、标签、词性、设置均为左标签、右控件的 inline 布局。
5. 集合菜单：卡片右上角三点菜单包含编辑和删除；删除弹窗确认后执行逻辑删除。
6. 集合测试：每组接口固定请求 10 题；完成后显示整组结果，错题自动入错题本，并提供“再来一组”“返回”。
7. 词汇显示：词库和集合学习共用显示 Hook；三个字段开关与默记模式互斥，隐藏显示 `•••`，单元格可临时揭示，词汇链接进入详情。
8. 知识关联：词汇、语法、句子详情页相互独立；统一编辑器支持创建时选择关联；详情关联通过浮层维护；词汇详情“造句”复用句子创建功能。
9. 多项选择：自定义 `FilterMultiSelect` 支持输入筛选、紧凑选项和已选标签，不平铺 Checkbox。
10. Loading：查询、登录、退出、增删改、关联、学习和测试使用页面级 Loading，操作期间锁定重复提交。
11. 时间：统一由 `formatDateTime` 输出 `YYYY-MM-DD HH:mm:ss`。
12. 词性：移除导入审核导航；指定七项排序为 10–70；查询升序；新增最大值加 10；列顺序为名称、代码、序号、状态；序号只读。
13. 标签：前后端固定十色；颜色下拉直接显示色块；标签在知识详情和选择控件中渲染背景色。
14. 主题：Chakra 调色板和 Less 变量集中配置，当前为橙黄色主题。
15. 移动端：所有桌面表格在移动端切换为信息卡片，不显示表格操作按钮。
16. 启动日志：修复缺少 context 时传入 `undefined`；删除重复启动输出，只保留一条 STARTUP 日志。
17. API：查询只用 GET，变更只用 POST；Swagger 验证 PUT/DELETE 为 0、路径参数为 0。
18. 前端接口：全部集中到 `src/http/api/` 单一方法；源码扫描确认目录外没有直接 `request()`。
19. 登录：用户密码按测试要求明文存储、明文比对；保留 HttpOnly Cookie 和会话令牌摘要，后者不改变密码明文要求。
