# 文章数据源

本目录保存文章模块的 Markdown 正文。除本说明文件外，每个 Markdown 文件都与在线 MySQL 的一条 `articles` 记录逐字一致。

## 同步规则

- 数据库与本目录必须同步维护，新增或修改文章时同时更新两处。
- 文件名用于仓库阅读，数据库关联仍使用文章 ID 和类别 ID。
- 网站运行时读取在线 MySQL，本目录用于来源追踪、版本管理和恢复。
