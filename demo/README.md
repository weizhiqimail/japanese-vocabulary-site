# 日本語言葉勉強 V2 前端 Demo

本目录是独立的纯前端交互 Demo，不连接正式站点、数据库或 API。初始化数据写入浏览器 `localStorage`，新增、收藏、掌握、审核、设置及词汇—语法—句子关联在刷新后继续保留；可在“管理 > 设置”中重置为初始数据。

## 本地运行

```powershell
cd demo
npm install
npm run dev
```

构建验证：

```powershell
npm run build
```

## 页面范围

- 首页
- 词汇集合与集合学习页
- 复习：错题本、掌握记录、收藏本
- 测试：词汇、语法、混合测试
- 正式词库、词汇详情
- 语法库、语法详情
- 句子库、句子详情
- 文章占位页
- 管理：AI 导入审核、标签、词性、设置

页面使用浏览器 History 路由，不使用 Hash。分页、筛选等状态保存在普通 URL 查询参数中。

所有列表页面共用底部居中的统一分页，包含上一页、页码、下一页、跳转和“每页 X 条”，不在页面顶部重复提供 `pageSize`。

Vite 开发服务器会自动把未知页面路径回退到 `index.html`。`public/_redirects` 会进入构建产物，为支持该规则的静态托管平台提供 `/* /index.html 200` 回退。部署到其他 Web 服务器时，也必须将不存在的前端路由重写到 `/index.html`，否则直接刷新 `/words` 等页面会返回 404。
